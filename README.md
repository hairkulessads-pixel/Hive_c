# Hive_c

Hive_c is a creator marketplace platform for brands to discover influencers, launch campaigns, and track earnings. The project is built with React and Tailwind CSS.

## Codex web

Codex is OpenAI's coding agent that can read, edit, and run code. It helps you build faster, fix bugs, and understand unfamiliar code. With Codex cloud, Codex can work on tasks in the background, including in parallel, using its own cloud environment.

### Codex web setup

1. Go to [Codex](https://chatgpt.com/codex).
2. Connect your GitHub account so Codex can work with code in your repositories and create pull requests from its work.
3. Use an eligible Plus, Pro, Business, Edu, or Enterprise plan. For plan details, see [what's included](https://developers.openai.com/codex/pricing).
4. If you are on an Enterprise workspace, you may also need [admin setup](https://developers.openai.com/codex/enterprise/admin-setup) before Codex web is available.

### Work with Codex web

Use these guides to get started:

- [Learn about prompting](/codex/prompting#prompts): Write clearer prompts, add constraints, and choose the right level of detail to get better results.
- [Common workflows](/codex/workflows): Start with proven patterns for delegating tasks, reviewing changes, and turning results into pull requests.
- [Configuring environments](/codex/cloud/environments): Choose the repo, setup steps, and tools Codex should use when it runs tasks in the cloud.
- [Delegate work from the IDE extension](/codex/ide/features#cloud-delegation): Kick off a cloud task from your editor, then monitor progress and apply the resulting diffs locally.
- [Delegating from GitHub](/codex/integrations/github): Tag `@codex` on issues and pull requests to spin up tasks and propose changes directly from GitHub.
- [Control internet access](/codex/cloud/internet-access): Decide whether Codex can reach the public internet from cloud environments, and when to enable it.
